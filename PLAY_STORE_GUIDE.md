## 📦 Option 2: Publishing to the Official Google Play Store

To release **Slynks** on the Google Play Store so users can search and download it:

### Method A: Using Google's Official Bubblewrap CLI (Automated APK/AAB)

Google provides **Bubblewrap**, the official tool that converts PWAs into Google Play Store `.aab` (Android App Bundle) packages:

1. **Install Bubblewrap**:
   ```bash
   npm install -g @bubblewrap/cli
   ```

2. **Initialize from your live website**:
   ```bash
   bubblewrap init --manifest="https://husnain-tech-png.github.io/slynks-hydroponic-controller/manifest.json"
   ```

3. **Build the signed Android App Bundle (`app-release-bundle.aab`)**:
   ```bash
   bubblewrap build
   ```

4. **Upload to Google Play Console**:
   - Go to [play.google.com/console](https://play.google.com/console).
   - Create a new app named **"Slynks - Hydroponic IoT Controller"**.
   - Upload the `app-release-bundle.aab` generated by Bubblewrap.
   - Upload the icon `assets/icon-512.png` and screenshots.
   - Submit for Google Play Store review!

---

### Method B: Using PWABuilder (1-Click Online Generator)

1. Open **[PWABuilder.com](https://www.pwabuilder.com/)**.
2. Enter your URL: `https://husnain-tech-png.github.io/slynks-hydroponic-controller/`.
3. Click **"Package for Stores"** ➔ Select **Android**.
4. Set App Name to **Slynks** and Package ID to `cloud.slynks.hydroponics`.
5. Download your signed `.apk` (for direct Android phone installation) or `.aab` (for Google Play Store upload).
